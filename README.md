# Blog API

REST API и административная панель для мобильного приложения «Блог».

Проект позволяет пользователям регистрироваться и авторизовываться, создавать публикации, просматривать общую ленту и список собственных публикаций.

Административная панель реализована с использованием Filament.

## Стек

- PHP 8.2+
- Laravel
- MySQL 8.0+
- Laravel Sanctum
- Filament
- Composer

## Возможности

### API

- Регистрация пользователя
- Авторизация пользователя
- Bearer Token авторизация через Laravel Sanctum
- Создание публикаций
- Получение всех публикаций
- Получение собственных публикаций
- Пагинация через `limit` и `offset`
- Сортировка по дате
- Сортировка по заголовку
- Фильтрация публикаций по диапазону дат
- JSON-ответы API
- Валидация входных данных

### Административная панель

- Авторизация администратора
- Ограничение доступа к панели по роли
- CRUD пользователей
- CRUD публикаций
- Просмотр автора публикации

## Архитектура

Проект построен на архитектуре MVC.

Бизнес-логика API вынесена из контроллеров в отдельные сервисы:

```text
app/
├── Http/
│   └── Controllers/
│       └── Api/
│           ├── AuthController.php
│           └── PostController.php
│
├── Models/
│   ├── User.php
│   └── Post.php
│
└── Services/
    ├── AuthService.php
    └── PostService.php
